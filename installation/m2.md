# Jellyfin Media Stack: manuelle Einrichtung

Diese Anleitung beschreibt die manuelle Einrichtung nach der Initialisierung des Stacks. Führe nur die Abschnitte für Dienste aus, die du in `init.sh` ausgewählt hast.

> Verwende den Stack nur für Medien, die du rechtmäßig speichern und verwenden darfst.

## 1. Stack initialisieren

```bash
curl -fsSL https://raw.githubusercontent.com/florianthepro/jellyfin-media-stack/main/installation/bash/init.sh | sudo bash
```

Die Initialisierung prüft das System, bereinigt eine vorhandene Projektinstallation, erstellt die gewählte Compose-Konfiguration und startet die ausgewählten Dienste.

## 2. Status und Adressen ermitteln

```bash
cd /opt/jellyfin-media-stack
sudo docker compose ps
hostname -I
```

Verwende die erste passende Server-IP aus `hostname -I` für die Weboberflächen:

- Jellyfin: `http://SERVER-IP:8096`
- Seerr: `http://SERVER-IP:5055`
- Sonarr: `http://SERVER-IP:8989`
- Radarr: `http://SERVER-IP:7878`
- Prowlarr: `http://SERVER-IP:9696`
- qBittorrent: `http://SERVER-IP:8080`

Docker-intern werden die Dienste über ihren Servicenamen erreicht, beispielsweise `http://sonarr:8989`.

## 3. Jellyfin einrichten

1. Jellyfin unter `http://SERVER-IP:8096` öffnen.
2. Sprache auswählen.
3. Administratorkonto mit sicherem Kennwort erstellen.
4. Bibliothek **Filme** hinzufügen:
   - Inhaltstyp: Filme
   - Ordner: `/media/movies`
5. Bibliothek **Serien** hinzufügen:
   - Inhaltstyp: Serien
   - Ordner: `/media/series`
6. Metadatensprache und Region festlegen.
7. Remotezugriff nach Bedarf aktivieren.
8. Automatische Portfreigabe deaktiviert lassen, sofern sie nicht ausdrücklich benötigt wird.
9. Assistent abschließen.

## 4. qBittorrent einrichten

Diesen Abschnitt überspringen, wenn qBittorrent nicht ausgewählt wurde.

### Temporäres Kennwort anzeigen

```bash
sudo docker logs qbittorrent 2>&1 | grep -i -A2 'temporary password'
```

Anmeldung:

- Benutzer: `admin`
- Kennwort: temporäres Kennwort aus dem Container-Log

Danach in qBittorrent:

1. `Tools` > `Options` > `Web UI` öffnen.
2. Ein dauerhaftes, sicheres Kennwort festlegen.
3. Unter `Downloads` den Standard-Speicherpfad auf `/downloads` setzen.
4. Änderungen speichern.

## 5. Sonarr einrichten

Diesen Abschnitt überspringen, wenn Sonarr nicht ausgewählt wurde.

1. Sonarr unter `http://SERVER-IP:8989` öffnen.
2. Falls verlangt, Authentifizierung aktivieren und Zugangsdaten festlegen.
3. `Settings` > `Media Management` öffnen.
4. Gewünschte Einstellungen für Benennung und Medienverwaltung setzen.
5. Als Root Folder `/tv` hinzufügen.
6. `Settings` > `Download Clients` öffnen.
7. qBittorrent hinzufügen:
   - Host: `qbittorrent`
   - Port: `8080`
   - Benutzer: `admin`
   - Kennwort: dauerhaftes qBittorrent-Kennwort
   - Kategorie: `sonarr`
8. Verbindung testen und speichern.
9. API-Key unter `Settings` > `General` notieren. Er wird später für Prowlarr und Seerr benötigt.

## 6. Radarr einrichten

Diesen Abschnitt überspringen, wenn Radarr nicht ausgewählt wurde.

1. Radarr unter `http://SERVER-IP:7878` öffnen.
2. Falls verlangt, Authentifizierung aktivieren und Zugangsdaten festlegen.
3. `Settings` > `Media Management` öffnen.
4. Gewünschte Einstellungen für Benennung und Medienverwaltung setzen.
5. Als Root Folder `/movies` hinzufügen.
6. `Settings` > `Download Clients` öffnen.
7. qBittorrent hinzufügen:
   - Host: `qbittorrent`
   - Port: `8080`
   - Benutzer: `admin`
   - Kennwort: dauerhaftes qBittorrent-Kennwort
   - Kategorie: `radarr`
8. Verbindung testen und speichern.
9. API-Key unter `Settings` > `General` notieren. Er wird später für Prowlarr und Seerr benötigt.

## 7. Prowlarr einrichten

Diesen Abschnitt überspringen, wenn Prowlarr nicht ausgewählt wurde.

### Indexer hinzufügen

1. Prowlarr unter `http://SERVER-IP:9696` öffnen.
2. `Indexers` öffnen und über `+` die gewünschten, rechtmäßig nutzbaren Indexer hinzufügen.
3. Jeden Indexer testen und speichern.

### Sonarr verbinden

Unter `Settings` > `Apps` Sonarr hinzufügen:

- Name: `Sonarr`
- Prowlarr Server: `http://prowlarr:9696`
- Sonarr Server: `http://sonarr:8989`
- API-Key: API-Key aus Sonarr
- Sync Level: gewünschte Synchronisierungsstufe

Verbindung testen und speichern.

### Radarr verbinden

Unter `Settings` > `Apps` Radarr hinzufügen:

- Name: `Radarr`
- Prowlarr Server: `http://prowlarr:9696`
- Radarr Server: `http://radarr:7878`
- API-Key: API-Key aus Radarr
- Sync Level: gewünschte Synchronisierungsstufe

Verbindung testen und speichern.

## 8. Seerr einrichten

Diesen Abschnitt überspringen, wenn Seerr nicht ausgewählt wurde.

1. Seerr unter `http://SERVER-IP:5055` öffnen.
2. Jellyfin als Medienserver auswählen.
3. Als interne Jellyfin-Adresse `http://jellyfin:8096` verwenden.
4. Mit dem zuvor erstellten Jellyfin-Administratorkonto anmelden.
5. Jellyfin-Bibliotheken synchronisieren.
6. Sonarr hinzufügen:
   - Hostname: `sonarr`
   - Port: `8989`
   - API-Key: Sonarr API-Key
   - Root Folder: `/tv`
   - gewünschtes Qualitätsprofil auswählen
7. Radarr hinzufügen:
   - Hostname: `radarr`
   - Port: `7878`
   - API-Key: Radarr API-Key
   - Root Folder: `/movies`
   - gewünschtes Qualitätsprofil auswählen
8. Verbindungen testen und Einrichtung abschließen.
9. Benutzerrechte, Freigaben und Genehmigungsregeln überprüfen.

## 9. Tailscale prüfen

Diesen Abschnitt überspringen, wenn Tailscale nicht ausgewählt wurde.

```bash
sudo docker exec tailscale tailscale status
sudo docker exec tailscale tailscale ip -4
```

Wenn der Status `NeedsMachineAuth` zeigt, das neue Gerät in der Tailscale-Administrationsoberfläche freigeben:

```text
https://console.tailscale.com/admin/machines
```

Danach den Status erneut prüfen. Der verwendete Auth-Key kann unter folgender Adresse verwaltet oder widerrufen werden:

```text
https://console.tailscale.com/admin/settings/keys
```

## 10. Funktionstest

### Container prüfen

```bash
cd /opt/jellyfin-media-stack
sudo docker compose ps
```

Alle ausgewählten Dienste sollten den Status `Up` beziehungsweise `running` anzeigen.

### Einzelne Logs prüfen

```bash
sudo docker compose logs --tail=100 jellyfin
sudo docker compose logs --tail=100 seerr
sudo docker compose logs --tail=100 sonarr
sudo docker compose logs --tail=100 radarr
sudo docker compose logs --tail=100 prowlarr
sudo docker compose logs --tail=100 qbittorrent
sudo docker compose logs --tail=100 tailscale
```

Nur Befehle für tatsächlich ausgewählte Dienste ausführen.

### Ablauf testen

1. Jellyfin-Anmeldung testen.
2. In Sonarr und Radarr die Root Folder prüfen.
3. Download-Client-Verbindungen testen.
4. Prowlarr-Verbindungen zu Sonarr und Radarr testen.
5. In Seerr eine Verbindungssynchronisierung durchführen.
6. Prüfen, ob vorhandene Filme und Serien in Jellyfin erkannt werden.

## 11. Verwaltung

### Stack starten

```bash
cd /opt/jellyfin-media-stack
sudo docker compose up -d
```

### Stack stoppen

```bash
cd /opt/jellyfin-media-stack
sudo docker compose down
```

### Status anzeigen

```bash
cd /opt/jellyfin-media-stack
sudo docker compose ps
```

### Images aktualisieren

```bash
cd /opt/jellyfin-media-stack
sudo docker compose pull
sudo docker compose up -d --remove-orphans
```

### Laufende Logs anzeigen

```bash
cd /opt/jellyfin-media-stack
sudo docker compose logs -f --tail=100
```

### Initialisierungsprotokoll anzeigen

```bash
sudo cat /var/log/jellyfin-media-stack-initial.log
```

### Schnittstellen-Debugprotokoll anzeigen

```bash
sudo cat /var/log/jellyfin-media-stack-interfaces.log
```

## 12. Pfade und Sicherung

Konfiguration:

```text
/opt/jellyfin-media-stack/.env
/opt/jellyfin-media-stack/compose.yaml
/opt/jellyfin-media-stack/data/
```

Medien liegen im während der Initialisierung erkannten oder angegebenen Medienpfad, standardmäßig:

```text
/srv/media/movies
/srv/media/series
/srv/media/downloads
```

Vor Änderungen oder Updates sollten mindestens folgende Bereiche gesichert werden:

```bash
sudo tar -czf jellyfin-media-stack-config-backup.tar.gz \
  /opt/jellyfin-media-stack/.env \
  /opt/jellyfin-media-stack/compose.yaml \
  /opt/jellyfin-media-stack/data
```

Die Medien selbst müssen unabhängig davon entsprechend ihrer Größe und Bedeutung gesichert werden.
